# Security Policy

## Supported Versions

Security fixes apply to the latest published version of each package (`@ktjn/designed-tokens`, `@ktjn/designed-icons`, `@ktjn/designed-react`) on `main`.

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through [GitHub Security Advisories](https://github.com/ktjn/designed/security/advisories/new) with:

- Affected package and version
- Minimal reproduction or proof of concept
- Potential impact and any suggested remediation

You should receive an acknowledgment within 5 business days.
