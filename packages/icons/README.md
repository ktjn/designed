# @ktjn/designed-icons

Monochrome SVG icons generated as tree-shakeable React components using `currentColor`.

## Install

```sh
pnpm add @ktjn/designed-icons
```

## Usage

```tsx
import { CalendarIcon, SearchIcon } from "@ktjn/designed-icons";

<SearchIcon aria-hidden size={16} />;
```

## Icon sources

The catalog includes SVGs from [Lucide](https://lucide.dev/), sourced from
`lucide-static@1.77.0`. See [LICENSE-LUCIDE](LICENSE-LUCIDE) for the upstream notices.
The SVG class names record the upstream icon names where they differ from the React exports.
